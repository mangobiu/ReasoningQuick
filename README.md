# 推理强度快调 (TT-ReasoningQuick)

在 TauriTavern / SillyTavern 的**左下角魔棒菜单**里，加入一排推理强度档位按钮（自动 / 极低 / 低 / 中 / 高 / 超高 / 最高），点一下即切换，不用再进「AI 响应配置」面板翻找。

当前档位会高亮显示，在其他地方改动推理强度时，按钮状态会自动同步。

## 安装方式

### 方式一：GitHub 仓库（推荐，支持在线安装与更新）

1. 注册/登录 GitHub → 右上角 `+` → **New repository**，名字随意（如 `TT-ReasoningQuick`），选 **Public**。
2. 点 **uploading an existing file**，把本文件夹里的 3 个文件（`manifest.json`、`index.js`、`style.css`）拖进去 → Commit。
3. 打开 TT → 扩展面板 → **安装扩展** → 填入你的仓库地址：
   `https://github.com/你的用户名/TT-ReasoningQuick`
4. 装完到「管理拓展」里勾选启用，重启一次页面。

### 方式二：本地放置（免 GitHub）

把整个 `TT-ReasoningQuick` 文件夹放进 TT 数据目录下的：

```
default-user/extensions/TT-ReasoningQuick
```

（找不到 `extensions` 文件夹就新建一个），然后重启 TT，在「管理拓展」里勾选启用。

## 使用

### 输入框上方的档位条（v1.2.0+，v1.4.0 起并入快捷回复栏）

聊天输入框上方有一条常驻档位条：**低 / 高 / 极高 / 最高**，点一下就切，当前档亮起。
当前档不在四档里（比如预设给了 auto / 中）时，会自动在末尾补一个对应档位。

- v1.4.0 起：档位条优先并入快捷回复栏 `#qr--bar` 的最右边（两排并一排）；胶囊改成与快捷回复按钮同款（透明底 + 描边 + 全圆角），当前档用主题强调色点亮；自身背景全透明。
- 没有快捷回复栏时退回输入框上方独立一行（靠右）。
- 接口不支持推理强度时整条变淡且点不动。
- 想改高度/最小宽，改 `style.css` 里 `#rqs_bar` 顶部的 `--rqs-h` / `--rqs-minw` 两个变量即可。

### 魔棒菜单

1. 点聊天界面左下角**魔棒**。
2. 菜单里出现「🧠 推理强度」一栏，点任意档位即切换，当前档位高亮。
3. 只在 Chat Completion 系接口（OpenAI 兼容 / Claude / Gemini / 自定义等）下有效；原生文本补全类接口没有这个参数。

## 更新日志

- **v1.4.0**：档位条并入快捷回复栏（无 QR 栏时退回输入框上方）；胶囊与快捷回复按钮同款描边样式，当前档用主题强调色；自身背景全透明（需配合 TT 自定义 CSS 清除旧亮带，见交付说明）。
- **v1.3.0**：档位条改为右对齐分段控件（高度 36px → 30px，去掉图标与逐格边框）；切换不再弹 toast；接口不支持时置灰禁用；档位条改为加载后立即出现（原来最多等 2.5 秒）。
- **v1.2.0**：新增输入框上方常驻档位条。
- **v1.1.0**：启动 / 切模型 / 切预设时自动恢复「高」。

## 说明

- 本扩展只是改宿主自带的 `#openai_reasoning_effort` 控件并触发其原生保存逻辑，不额外发包、不读聊天内容。
- 「超高 / 最高」等档位是否生效取决于模型与接口，宿主会自动就近映射。
- 若魔棒菜单里没出现条目，请确认扩展已勾选启用，并刷新页面重试。
